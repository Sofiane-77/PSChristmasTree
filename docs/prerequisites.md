# Prerequisites

You need to meet the following requirement before using the module:

- PowerShell 5.1 or newer

### PowerShell Version

This module requires PowerShell 5.1 or newer.
Using a recent PowerShell version is recommended for the best cross-platform experience.

Carol playback uses built-in Windows and macOS capabilities. On Linux, it uses a compatible player already available in the environment (`pw-play`, `paplay`, or `aplay`). Music is optional; an unavailable player does not prevent tree rendering.
